- Python V1

Application console simple en Python pour gérer ses taches quotidiennes.

Fonctionnalites
 – Ajouter une taches : Ajoute une tâche à la liste (refuse les saisies vides)
 – Afficher les taches : Liste toutes les tâches enregistrées.
 – Rechercher une taches : Filtre les tâches par mot-clé
 – Quitter : Ferme l'application.

 Etapes realisees
. Developpement de la logique textuelle en Python (main.py)
. Versionnement local avec Git (commits multiples)
. Publication sur un dépôt distant GitHub

 Exécution
. Ouvrir le projet dans VS Code
. Ouvrir le fichier main.py
. Cliquer sur le bouton « Run Python File »  en haut a droite de VS Code
